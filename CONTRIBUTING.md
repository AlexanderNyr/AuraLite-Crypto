# Contributing — AuraLite-Crypto

Rules are taken in spirit from `AuraLite-Emulator/CORE_PLAN.md` and
`AuraLite-OS/docs/plans/`: plan over heroism, measurement over claim.

**Project identity:** `AuraLite-Crypto`, ticker `ALCRY`, chain-id
`auralite-test-1`, BFT-PoS, WASM. Changing this in code without an owner
decision is forbidden: see `ROADMAP.md` §0 and `docs/TICKER_AUDIT.md`.
Documentation language is English (owner decision, 2026-10-25).

## 1. A phase is the smallest unit of work

One phase (e.g. `C4`) = **one patch**
`patches/NNNN-C4-tx-format.patch`, containing:

1. code/config implementing exactly that phase's DoD;
2. test vectors and/or an integration scenario;
3. a **negative control (NC)**: proof that the test goes red without the fix
   (revert hunk in `docs/evidence/<phase>/nc.log`);
4. the updated status row in its plan;
5. updates to `docs/STATUS.md` and `CHANGELOG.md`;
6. where needed, a record in `docs/evidence/<phase>/`.

If any item is missing, the phase is not closed and the status stays 🚧.

## 2. Mandatory gates before closing a phase

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace               # unit + property + integration
make test                           # single entry point: all of the above + extra gates
make test-sanitize                  # Miri/ASan/UBSan where applicable
make test-determinism               # N runs, byte-identical state root (from X7)
make fuzz-smoke                     # short run of each fuzz target (from H3)
cargo deny check                    # licenses + advisories (from H1)
```

At C0 only `make test` is live; `test-sanitize`, `test-determinism` and
`fuzz-smoke` print explicit SKIP lines naming their owning phases (H3/C9/X7)
instead of pretending to pass. `cargo deny check` arrives with H1. A skipped
gate is never reported as green in `docs/STATUS.md`.

CI repeats the same commands across shards: `core`, `state`, `exec`,
`consensus`, `net`, `node`, `wallet`, `ecosystem`, `security`, `perf`. A shard
that does not run its main test is a dead gate — that is a separate defect
(see the lesson of `AuraLite-OS/MATURITY_AUDIT.md`: 27 unregistered cases).

## 3. Naming

- Phases: `<PLAN><N>` — `C0`, `S3`, `X7`, `B10`, `N4`, `D7`, `W5`, `E9`, `T8`,
  `H8`, `P6`, `O6`.
- Commits in the style of your repositories: `C4 update`, `B3-B5 update`,
  `Bugfix update`.
- Patches: `NNNN-<PHASE>-<slug>.patch`, sequential numbering, no gaps.
- Receipts: `docs/evidence/<phase>/<lane>.log` + `SHA256SUMS`.

## 4. Forbidden in consensus code

- `HashMap`/`HashSet` (nondeterministic iteration) — use `BTreeMap` or
  explicitly sorted vectors.
- `f64`/`f32`, `rand`, system clocks, `std::env`, network calls inside the VM.
- `unsafe` without a justification comment, a separate test and a Miri check.
- `serde` in tx/block/state formats — only `aura-codec`.
- Golden vectors generated by the code under test. C1's bech32 vectors come
  from an independent implementation (`tools/gen_c1_vectors.py`); a vector
  that only confirms the encoder agrees with itself is not a test. C2's codec
  vectors come from `tools/gen_c2_vectors.py`.
- Changing the `aura-codec` wire format without bumping `CODEC_VERSION` and
  adding a migration test. One value must have exactly one byte encoding.
- Unpinned dependencies. Since C3 every external crate uses an exact `=x.y.z`
  pin in `[workspace.dependencies]`, is checksummed in `Cargo.lock`, and is
  recorded in `docs/spec/c3-dependency-allowlist.txt`. Adding one requires a
  dedicated phase patch, `make record-c3-deps` and an NC. `make check-deps`
  enforces this; `cargo deny` (licences/advisories) arrives with H1.
- "Temporary" stubs that silently return success. A stub must explicitly
  return `Err(Unimplemented)` and be visible in STATUS.
- Format changes without a protocol version and a migration test.

## 5. Secrets and releases

- Private keys, mnemonics, API tokens, keystores **never** enter git.
  `.gitignore` + `gitleaks` in CI (H1).
- Genesis validator keys are generated offline; only public keys land in the
  tree. The procedure is described in `WALLET_PLAN` W7 and `OPS_PLAN` O5.
- Releases are signed outside CI, reproducibly (`OPS_PLAN` O1), with an SBOM.

## 6. Documentation

- Language: English; technical identifiers, commands and standard names stay
  in English too.
- Every number in the docs is accompanied by the command that produces it.
- "Works" is written only about something covered by a gate. Everything else
  is "experimental", "planned" or "not implemented".
- A discovered plan/tree mismatch is filed as an `⚠️ AUDIT` entry, not quietly
  fixed in the plan text.

## 7. Review checklist

- [ ] The phase DoD is fully met, not "almost".
- [ ] Gate is green; log/receipt attached.
- [ ] NC demonstrated (test goes red without the fix).
- [ ] No format changes without a version bump.
- [ ] `docs/STATUS.md`, `CHANGELOG.md`, plan row updated.
- [ ] New dependency pinned and passed `make check-deps` (`cargo deny` at H1).
- [ ] Tx wire format unchanged, or `CODEC_VERSION` bumped and
      `docs/spec/tx-format.md` + golden vectors updated in the same patch.
- [ ] Block wire format unchanged, or `PROTOCOL_VERSION` bumped and
      `docs/spec/block-format.md` + golden vectors updated in the same patch.
- [ ] Merkle proof format unchanged, or `docs/spec/merkle-proof-format.md`
      and `tools/gen_c6_vectors.py` updated in the same patch.
- [ ] State key layout unchanged, or `PROTOCOL_VERSION` bumped and
      `docs/spec/account-model.md` + `tools/gen_c7_vectors.py` updated in the
      same patch (reserved prefixes must stay unreachable from contracts).
- [ ] Genesis schema unchanged, or `docs/spec/genesis-format.md`,
      `genesis-testnet.json` and `tools/gen_c8_vectors.py` updated together.
- [ ] New external dependency? `make record-deps` + a reviewed addendum;
      never rewrite the frozen C3 baseline allowlist.
- [ ] `make vector-inventory` still >= 200 and `make test-core` /
      `make fuzz-smoke` still run in CI (`tools/check_rig.py`).
- [ ] `make audit-closeout` green: every ✅ phase has a patch, receipt,
      CHANGELOG entry, NC log and verified evidence.
- [ ] No new `unsafe` without justification.
- [ ] The north star was not pushed aside by a "temporary" solution.
